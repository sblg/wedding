# Sara & Mads — Wedding Website

A simple, responsive, trilingual wedding website for 28 August 2027.

## Included
- `index.html` — the complete website (HTML, CSS and JavaScript in one file)
- Language switcher: English, Danish and Portuguese
- Wedding schedule, venue directions, Lisbon Airport travel notes and Lezíria Parque Hotel
- RSVP section with a placeholder button

## Before sharing with guests
1. Open `index.html` in a browser and review the site.
2. Replace the sample schedule times if needed.
3. Replace the RSVP deadline in all three languages.
4. Create a Google Form for RSVPs.
5. In `index.html`, find `https://forms.google.com/` and replace it with your actual Google Form URL.
6. In the RSVP section, remove or edit the note explaining that the button is a placeholder.

The RSVP button is intentionally a placeholder: this static website does not collect or store guest responses by itself. Connect it to a Google Form before publishing.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a new public repository, for example `wedding`.
3. Upload `index.html` to the repository's root folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will provide a public website address after publishing. It may take a few minutes.

You can update the site later by editing and uploading `index.html` again.

## Notes
- The page uses Google Fonts, so typography loads from the internet.
- Map, hotel and directions links open Google Maps or the hotel's website.
- No guest data is collected by this website.
